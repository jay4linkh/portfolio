# Jay Gupta · Portfolio

Live site: https://jaygupta.vercel.app

Everything on the page comes from **`content.json`**. Edit that one file (on GitHub you can do it from your phone: open the file, tap the pencil, commit) and Vercel redeploys the site in about a minute.

- `index.html`: page structure and social preview tags
- `styles.css`: design (light and dark themes)
- `app.js`: renders `content.json` and draws the hero animation
- `og.png`: the preview image LinkedIn shows
